## Bank Account Management System Using Python
## Introduction
The Bank Account Management System is a menu-driven application developed using Python. It performs basic banking activities such as checking account balance, depositing money, withdrawing money, and viewing transaction details.
The main purpose of this project is to understand Python programming fundamentals through a real-world banking example.
## Project Goals
1.To create a simple banking application.
2.To understand the use of Python functions.
3.To implement loops and conditional statements.
4.To manage account balance efficiently.
5.To maintain a record of transactions.
6.To handle invalid user inputs.
##  Software Requirements
Language	Python
##  Main Modules
1.Account Balance
2.Displays the amount currently available in the account.
3.Deposit
4.Accepts an amount from the user and adds it to the account balance.
5.Withdrawal
6.Deducts the requested amount after checking the available balance.
7.Transaction Records
8.Maintains a list of completed deposits and withdrawals.
9.Menu System
10.Provides options to perform different banking operations.
##  Working Procedure
1.Start the Python application.
2.Enter the account holder's name.
3.Select an operation from the menu.
4.Enter the required amount if necessary.
5.The system validates the input.
6.The account balance is updated.
7.Transactions are stored in a list.
8.The user can continue until selecting Exit.
##  Execution Instructions
Step 1: Install Python 3 on your computer.
Step 2: Open the project folder in code.
Step 3: Open the terminal.
Step 4: Execute the following command:bash
BANK_ACCOUNT_SIMULATOR.PY
Step 5: Select the required banking operation from the menu.

##  Validation and Error Handling
The application handles the following situations:
Rejects negative deposit amounts.
Rejects zero-value transactions.
Prevents withdrawals exceeding the available balance.
Handles invalid numeric inputs.
Displays an error message for incorrect menu selections.

After completing this project, we can understand:
Python function creation and usage.
Working with lists.
Using while loops.
Implementing if-elif-else conditions.
Handling exceptions using try-except.
Managing application state using variables.

The Bank Account Simulator was successfully developed using Python, performing balance checking, deposits, withdrawals, and transaction history management with proper input validation.
